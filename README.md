# Java Lab Assignment

A collection of four Java console applications created as part of my Software Engineering studies at Ala-Too International University.

## Projects

### 1. GradeTracker
A grade management application that allows users to:
- Add assignment and exam scores.
- Calculate average scores.
- Determine the overall grade.
- Display letter grades (A, B, C, D, F).

### 2. ScreenTimeTracker
A screen time tracking application that allows users to:
- Record time spent on social media, gaming, studying, and streaming.
- Calculate total screen time.
- View statistics for different activities.
- Compare study time with entertainment time.

### 3. StoreCheckout
A simple store checkout system featuring:
- Product selection and quantity management.
- Automatic subtotal calculation.
- Discounts based on purchase amount and quantity.
- Payment processing and change calculation.
- Purchase receipts and reward coupons.

### 4. StudyTracker
A study time management application that allows users to:
- Record study sessions by subject.
- Track time spent on programming, mathematics, English, and other subjects.
- View study statistics.
- Set and track a weekly study goal of 600 minutes.

## How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Navigate to the `src` folder.
4. Open the Java file you want to run.
5. Run the program using its `main` method.
